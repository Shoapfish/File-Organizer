# 📂 Python File Organizer (BSIS Tech Hacks)

A lightweight Python script that automatically categorizes and organizes cluttered files into designated subfolders base on file extensions.

---

## 🛠️ Requirements
* **Python 3.x** installed on your system.
* Built-in Python modules used: `os`, `shutil`

---
